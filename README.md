# 세계 음식대백과 V2 Stage 1.20

Stage 1.19 정상 화면과 자료를 기준으로, 사진 후보가 있는 항목의 수동 카드 만들기를 보강한 판입니다.

## 반영 내용
- 나라검색 부분검색/대륙정렬 기능 유지
- 부모모드에서 사진 후보가 있는 보라색 항목은 설명이 부족해도 `선택한 사진으로 임시 카드 만들기` 허용
- 임시 카드는 `설명 보강 필요` 상태를 남기고, 부모모드에서 나중에 한국어 설명을 수정할 수 있음
- 오검색 격리/차단 권고 항목은 여전히 카드 만들기 차단
- 기존 홈/나라탐험/음식탐험/부모모드 화면과 저장자료 유지
