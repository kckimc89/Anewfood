# 세계 음식대백과 V2 Stage 1.13

Stage 1.10의 홈/나라탐험/음식탐험 화면을 보존한 상태에서 자동검색 엔진을 보강한 판입니다.

## 핵심 변경
- 기존 화면 구조 보존
- 560개 전체 별칭 유지
- 후보 143개 1차 카드화 데이터 유지
- 자동검색 순서: 한국어 위키 → 영어 위키 → 국가별 주요 원어 위키
- 영어/원어 후보는 보라색 후보로만 저장
- 초록색 자동 전환 없음
- 기존 완성 카드와 사용자 직접 수정 내용은 보호

## 사용 전 권장
1. 현재 앱에서 전체 백업
2. ZIP 압축 해제 후 전체 파일을 GitHub 루트에 업로드
3. 새로고침 후 부모모드에서 숫자 확인
4. 실패 항목 재검색 실행
5. 재검색 후 품질검토 자료 내보내기
